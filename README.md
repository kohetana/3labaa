# 3labaa
## Задача
Вычисление числа Рейнольдса (Re) и коэффициента сопротивления (xi) для насадки химической колонны.

## Формулы
- Re = (W * l * rho) / mu
- xi = 2.62 / Re^0.65, если Re < 2500
- xi = 0.125 / Re^0.26, если Re >= 2500

## Параметры
- l = 0.015 м
- rho = 1.1 кг/м³
- mu = 1.8e-5 Па·с

## Ввод
5 значений скорости W (м/с) через пробел.
Пример: `1 2 5 10 20`
